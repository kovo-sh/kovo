SPEC 01 / WHY Scope & isolation

Self-hosted pentesting locked to your own software.

Like ARTEX, Kovo Guardian provides a self-hosted management UI so you can complete pentesting end-to-end in one simple UI.

ARTEX is extremely powerful, yet easy to misuse for developers and security engineers trying to protect their own applications. Kovo Guardian makes it simple to lock pentesting to your own apps and approved domains so you don't accidentally probe third-party hosts, mutate production data, or leak test credentials.

01 · AIR-GAPPED WORKERS

Workers run under --network=none. All traffic passes through the Host Request Broker enforcing strict scope allowlists, execution Tiers 0–3, and RPS circuit breakers.

02 · OPAQUE PERSONA VAULT

Run multi-user BOLA/IDOR authorization testing without ever exposing cookies or JWTs to the LLM. Personas remain sealed on the host.

03 · GREY-BOX + REPLAY

Full read-only /repos mounts for code context paired with 1-click deterministic Zero-LLM Verify Fix regression re-tests.

PROC 02 / INSTALL Three-step setup

Up and running in three steps.

01

Install

Runs on any laptop or small VM (exe.dev, DigitalOcean, Hetzner, etc.) with one Docker command, or build directly from source so you can verify you're running the exact audited source code.

docker run -p 8000:8000 -v guardian-data:/data ghcr.io/kovo-sh/guardian

Persists local run state in the guardian-data volume and opens the self-hosted UI on http://localhost:8000.

git clone https://github.com/kovo-sh/guardian.git
cd guardian && npm ci && npm run worker:build && npm run build && npm start

Requires Node.js 24+ and a local Docker daemon for isolated --network=none workers.

02

Setup AI Inference

Works with any OpenAI-compatible or Anthropic provider. Simplest & most cost-effective setup is an OpenRouter API key with DeepSeek v4.1 Flash (101726).

03

Launch Your First Pentest

Paste your website URL → approve discovered domains → optionally connect read-only GitHub repos & disposable test accounts → launch and verify fixes.
