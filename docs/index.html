Why Kovo

Red-team depth. Built for your own stack.

ARTEX proved autonomous AI agents can run real pentests end to end—but red-team tools are easy to misuse on your own software. Kovo brings that same autonomous depth with host-enforced guardrails, so you never probe third-party hosts, wreck production data, or leak test credentials.

  • Air-gapped workers

    Workers run with --network=none—they can’t even open a socket. Every request goes through a Host Request Broker enforcing your scope allowlist, Tiers 0–3, and rate limits.

    --network=noneTiers 0–3

  • Opaque persona vault

    Test multi-user and cross-tenant auth without ever showing cookies or JWTs to the LLM. Sessions stay sealed on the host; agents only see a placeholder.

    cross-tenant auth0 creds to LLM

  • Code-aware + replay proof

    Mount your repos read-only (/repos) so agents read your actual routes. Every confirmed finding ships with a deterministic replay—click Verify fix to retest with zero LLM tokens.

    /repos:roVerify fix

Proof

Receipts, not hallucinated reports.

AI security tools are notorious for false positives. Every confirmed finding stores the exact control vs. variant request—ship your patch, click Verify fix, and re-run it directly against your live app. No model in the loop.

  • Sessions from the vault. The broker injects them; agents see [redacted:user_b].

Install

First pentest in five minutes.

  1. 1

    Install

    One Docker command on any laptop or small VM—or build from source to run the exact code you inspect.

    Terminal
    $ docker run -p 8000:8000 -v kovo-data:/data ghcr.io/kovo-sh/kovo

    Keeps run state in the kovo-data volume and opens the self-hosted UI at http://localhost:8000.

    Terminal
    $ git clone https://github.com/kovo-sh/kovo.git
$ cd kovo && npm ci && npm run worker:build && npm run build && npm start

    Requires Node.js 24+ and a local Docker daemon for isolated --network=none workers.

  2. 2

    Bring your own model

    Plug in any OpenAI-compatible or Anthropic key. For the best speed-to-cost ratio, start with OpenRouter + DeepSeek v4.1 Flash.

FAQ

Questions.

Is Kovo free? What are the restrictions?

100% free and open source under Apache 2.0. Unlimited runs across all your apps—you only pay your own LLM provider.

Can it really not break production?

Workers run with --network=none, so every request passes through the host broker. You control the domain allowlist, RPS rate limits, and execution tier (Tiers 0–3, starting read-only), and test credentials stay sealed in the host vault—never shown to the LLM.

How does it compare to ARTEX, Strix and traditional scanners?

See Compare above. Kovo pairs autonomous, end-to-end AI pentesting (like ARTEX) with host-enforced guardrails built for your own software: air-gapped workers, broker-enforced scope tiers, an opaque persona vault, and deterministic zero-LLM replay verification.
