Don’t just trust the AI, verify.

Kovo Hunter catches vulnerabilities before attackers do. It runs on your machine, stays locked to the apps you approve, and confirmed findings carry a deterministic replay you can re-run after you ship the fix.

Get started GitHub

Press CtrlK to jump anywhere or copy the install command.

Self-hosted pentesting, locked to your own software.

Like ARTEX, Kovo Hunter gives you one self-hosted UI to run a pentest end to end. ARTEX is extremely powerful, but easy to misuse when you are protecting your own apps. Kovo Hunter makes it simple to lock testing to your apps and approved domains, so you don’t probe third-party hosts, mutate production data or leak test credentials.

Guarantees3enforced by the host, not the prompt

Air-gapped workers

Workers run under --network=none. All traffic passes through the Host Request Broker, which enforces the scope allowlist, execution Tiers 0–3 and RPS circuit breakers.

--network=noneTiers 0–3

Opaque persona vault

Run multi-user authorization tests (bola_idor) without ever exposing cookies or JWTs to the LLM. Personas stay sealed on the host; the model only sees a placeholder.

bola_idorsealed on host

Grey-box + replay

Read-only /repos mounts give agents code context. Confirmed findings carry a deterministic replay spec, and Verify Fix re-runs it as a retest with no LLM.

/repos:roVerify fix
ProofTry Verify fix on the sample

Findings come with a deterministic replay.

A confirmed finding stores a replay spec: the recorded request, a control and a variant. In the finding inspector, Verify fix queues a retest that re-sends exactly that spec against your live origin. No model in the loop.

  • Control vs. variant. Same request; only the session differs.
  • Sessions from the vault. The broker injects them; agents see [redacted:user_b].
  • Zero LLM tokens on retest. The verdict comes from the stored assertions.

Install3About five minutes

Up and running in three steps.

  1. 1

    Install

    Runs on any laptop or small VM (exe.dev, DigitalOcean, Hetzner, etc.) with one Docker command, or build from source so you can verify you’re running the exact audited code.

    Terminal
    $ docker run -p 8000:8000 -v kovo-data:/data ghcr.io/kovo-sh/kovo-hunter

    Keeps run state in the kovo-data volume and opens the self-hosted UI at http://localhost:8000.

    Terminal
    $ git clone https://github.com/kovo-sh/kovo-hunter.git
$ cd kovo-hunter && npm ci && npm run worker:build && npm run build && npm start

    Requires Node.js 24+ and a local Docker daemon for isolated --network=none workers.

  2. 2

    Set up AI inference

    Works with any OpenAI-compatible or Anthropic provider. The simplest and most cost-effective setup is an OpenRouter API key with DeepSeek v4.1 Flash.

    Model profileRecommended
    Provider
    OpenRouter
    Model
    DeepSeek v4.1 Flash deepseek/deepseek-v4.1-flash-1017
    Also works
    Any OpenAI-compatible or Anthropic endpoint
  3. 3

    Launch your first pentest

    From your website URL to a re-verified fix.

    1. Paste your website URL
    2. Approve the discovered domains
    3. Optionally connect read-only GitHub repos and disposable test accounts
    4. Launch, then verify fixes

Questions.

Is Kovo Hunter free? What are the restrictions?

Free and open source under Apache 2.0: unlimited pentest runs across all your applications, and you pay us nothing.

What is the Enterprise Edition?In development

For larger teams and organizations: SSO, configurable roles and RBAC, and scheduled routine pentest runs (for example weekly) with automated email and Slack reports. Contact us.

How does it compare to ARTEX, Strix and traditional scanners?

See Compare above. Kovo Hunter pairs ARTEX’s single self-hosted UI with defensive-first boundaries: air-gapped workers, broker-enforced scope tiers, an opaque persona vault, and deterministic zero-LLM replay verification.
