# Guardian v7 — Real-World Conversion & White-Box-First Verification

Status: draft (planning), 2026-11-23. v6 remains the shipped baseline until v7 M0 passes its gates.

## Thesis

v6 fixed the architecture: three layers, an always-on deterministic floor, a hard Layer-1 boundary, and script-based proof with an independent transcript oracle. v7 adds **no fourth layer**.

**v7 is about converting wired plumbing into confirmed real-world findings, then operating it safely and repeatedly.** White-box-first analysis and realism conversion come before SaaS/plugins/multi-tenancy.

Explicitly deferred: continuous scheduled scanning with a persistent org asset+code graph and PR-diff scanning (candidate for v8). Do not start it until M1/M2 pass.

## M0 — Proof unification, budget decoupling, DSL retirement (in progress)

Deliverables:
- Separate **Phase A floor** and **Phase B agent** request budgets (no borrowing), with honest `agent_budget_exhausted` reporting.
- **ProofReceipt**: one confirmation primitive `{ vulnClass, target, exchangeIds[], oobEventIds[], browserTraceIds[], claimedDelta }` validated by `verifyReceipt()` over host-signed transcripts using `oracle-invariants` in-process.
- Migrate floor confirmations, patch retest, and `pending_oob` promotions to receipts/proof scripts (in-process for Layer 2; sandbox double-run for Layer 3).
- Three deletion cuts: (1) agent compilers/fallback/legacy refinement queues; (2) floor/retest migration; (3) delete the spec VM and legacy verifier branches.

Gates: floor **≥31/59 with 0 spread**, xben 25/25, held-out 20/20 + 20/20, **Phase-1 certified** (worst-run precision 100%, +10pp dev / +8pp held-out), Realism #2 async SSRF **converted** to a confirmed finding, `execution.ts < 7.5K`, `replay-verifier < 1K` (or retired).

## M1 — Realism conversion (#1–#4)

- White-box AST/dataflow slices injected into Tier-A briefs (#4 → 3/3 4-hop).
- H2 race + workflow dispatch for #3 (write-BOLA/race/checkout).
- Pooled OIDC/CDN SPA + hybrid HTTP→browser ProofReceipt for #1.
- LabRunner YAML/Docker-network proxy retained; delete regex route extractors, 1-hop binding, old Compose parser/proxy.

Gate: #1–#4 **≥75% confirmed capability recall**, 100% precision; #2 async FN ≤10%; #3 zero leaked entities; #4 ≥2/3 4-hop confirmed.

## M2 — White-box-first program analysis and chains

- Interprocedural AST/dataflow, middleware/RBAC diffing, secrets/IaC.
- Typed chain primitives across coordinator rounds; reason-bench as a reasoning gate.
- Delete black-box-first overrides when source is mounted.

Gate: chains **≥4/6**, reason-bench agentic **≥40%** with `--no-llm` locked at 0/28, Tier-3 OSS dev ≥60% at ≥95% precision.

## M3 (deferred) — Continuous org graph + PR-diff scanning

Not in scope now. Revisit only after M1/M2 gates: persistent versioned asset/code graph, suppression feedback, PR/deploy blast-radius scanning (<5 min, <$0.50/PR).

## M4 — Production operations

- Signed scope manifest + **<2 s global kill switch**.
- ZDR/PII redaction, artifact TTL purge, per-tenant isolation and audit log.
- Honest coverage-gap reporting (auth_failed, waf_blocked, prod_readonly_skipped, oob_unreachable, uncovered_routes).
- Portable ProofReceipt export (signed transcript + reproducer + patch-retest proof).

Gate: sealed OSS held-out ≥60% at 100% precision, 0 FPs on clean negative-control apps, kill-switch/leak chaos test PASS.

## Evaluation portfolio (replaces local-benchmark hill-climbing)

1. **Frozen mechanical regression**: xben 25/25, held-out-saas 20/20 + patches, floor ≥55% 0-spread, unified ≥ floor +10pp, worst-run precision 100%.
2. **Realism Suite++**: #1–#4 now, #5 WAF/429 + introspection-off, #6 PR-diff later; ≥75% capability recall, 0 leaks, p99 store <10 ms.
3. **Real-world OSS/white-box corpus**: 8–10 pinned CVEs, 50/50 dev/sealed; ≥60% sealed recall, ≥95% precision, ≥80% patch retest.
4. **Reasoning + negative controls**: reason-bench (`--no-llm` 0/28 forever, agentic ≥40%), clean hardened repos 0 FPs.
5. **Contamination**: sealed held-outs only at milestone gates; CI lint forbids benchmark tokens in `src/server/`; always report TP per $1 and per 10 min.

## Cut list (do not build yet)

Multi-tenant SaaS, plugin/SDK ecosystem, cross-run ML priors, heavy triage UI, and continuous scanning. M1/M2 are hard-blocked behind M0.
