# Kovo CLI

The published source of `@kovo-security/cli`, synced from Kovo. The command is `kovo`.
Build with `npm ci --ignore-scripts` and `npm run build`; smoke with `node dist/kovo.js --version`.
Verify a consumer installation's provenance with `npm audit signatures`.
For issues, contact Kovo support. CLI usage is governed by the Kovo terms of service.
